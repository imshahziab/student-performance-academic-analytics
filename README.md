# Student Academic Performance & Grade Analytics

An exploratory and predictive data analytics project evaluating the behavioral and academic factors that influence student achievement using **Python**, **Pandas**, **Seaborn**, and **Scikit-Learn**.

---

## 📌 Project Overview
Academic success is driven by multiple interconnected variables including consistent engagement, prior educational baseline, and learning resources. This project explores key academic indicators and builds a linear regression model to quantify how study hours, attendance rates, and historical scores impact final grades.

### Core Objectives:
- **Exploratory Data Analysis (EDA):** Analyzed correlation patterns between attendance, weekly study hours, and performance outcomes.
- **Visual Analytics:** Designed feature correlation heatmaps and regression plots to highlight learning trends.
- **Predictive Modeling:** Implemented a Multivariate Linear Regression model to forecast final grades with evaluated R² scores and Mean Squared Error metrics.

---

## 🛠️ Tech Stack
- **Language:** Python 3
- **Data Manipulation:** Pandas, NumPy
- **Visualizations:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn (Linear Regression, Model Evaluation)
- **Environment:** Google Colab / Jupyter Notebook

---

## 📊 Key Findings
- **High Sensitivity to Study Hours:** Weekly study hours showed the highest positive correlation with final grades.
- **Attendance Impact:** Regular attendance rates above 75% created a noticeable baseline lift in overall student retention of course material.
- **Model Accuracy:** The regression baseline demonstrated consistent performance on unseen test splits.
